# Кібербібліотека — сервіс видачі книжок

Система для керування видачею паперових та електронних книжок користувачам.

## Функції
- видача паперових і електронних книжок
- черга на популярні видання
- нагадування про повернення

## Безпека
Про вразливості повідомляйте за правилами з SECURITY.md.

## Секрети і конфігурація

Для запуску застосунку скопіюйте шаблон `.env.example` у файл `.env` (він ігнорується Git) та заповніть змінні середовища:
- `EBOOKS_API_TOKEN` — токен доступу до API сервісу електронних книжок (видається в кабінеті партнера).
- `DATABASE_URL` — рядок підключення до бази даних (за замовчуванням `sqlite:///cyberlibrary.db`).
- `APP_ENV` — середовище запуску (`development`, `test`, `production`).
